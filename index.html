2. Pehli baar setup (sirf ek baar, 5 min)
  1. Is file ko Netlify Drop (app.netlify.com/drop) par drag-drop karo. Jo link milega (jaise https://....netlify.app) use note karo.
  2. console.cloud.google.com par naya project banao (naam: EMIAC Sales Dashboard), phir APIs and Services > Library me Gmail API Enable karo.
  3. OAuth consent screen me User type Internal chunno, app naam + support email bharo, scope me gmail.readonly add karo.
  4. Credentials > Create Credentials > OAuth client ID > Web application. Authorized JavaScript origins me Netlify wala link add karo. Client ID copy karo.
  5. Dashboard (Netlify link) kholo, upar Client ID paste karke Save karo, phir 3 mailbox ke Connect dabakar captain, ironman, batman chunno. Ho gaya, ab ye live hai.
